# PGM Flows Benchmarks

A benchmark suite for evaluating flow-based probabilistic models on Probabilistic Graphical Models (PGMs) with known structural equations.

## Overview

This package provides synthetic PGM benchmarks where each node is generated by a structural equation. This allows evaluation of posterior inference methods against analytical ground truth (where available) or high-quality samples.

## Abstract Mechanisms

The core of the benchmark suite is the use of structural equations. Each node $x_i$ in the graph is generated according to:

```math
x_i = f_i(\text{parents}(x_i), \text{noise}_i)
```

where $\text{noise}_i \sim \mathcal{N}(0, I)$ is independent Gaussian noise.

We support four types of abstract mechanisms, ranging from simple linear Gaussian models to fully flexible non-parametric functional relationships.

### 1. Linear
The classic Linear Gaussian mechanism.

```math
x_i = A_i \cdot \text{pa}_i + B_i \cdot \text{noise}_i + b_i
```

This results in a joint Gaussian distribution over all variables. $B_i$ is a lower-triangular matrix ensuring valid covariance.

### 2. Nonlinear Noise
A mechanism with linear dependency on parents but a nonlinear transformation of the noise.

```math
x_i = A_i \cdot \text{pa}_i + b_i + f(\text{noise}_i)
```

Here, $f(\cdot)$ is an odd, monotonic nonlinear function (implemented via Rational Quadratic Splines) that preserves the zero mean of the noise ($E[f(\epsilon)] = 0$). This allows for non-Gaussian marginals while maintaining linear expectations with respect to parents.

### 3. Nonlinear Parents
A mechanism with nonlinear mean and variance depending on parents, but with additive heteroscedastic Gaussian noise.

```math
x_i = \mu_{\theta}(\text{pa}_i) + \sigma_{\phi}(\text{pa}_i) \cdot \text{noise}_i
```

The functions $\mu_\theta$ and $\sigma_\phi$ are parameterized by neural networks. The conditional distribution $p(x_i | \text{pa}_i)$ is Gaussian, but the joint distribution is highly non-Gaussian.

### 4. Universal
A fully flexible mechanism capable of representing any invertible conditional distribution.

```math
x_i = \text{Spline}(\text{noise}_i; \theta(\text{pa}_i))
```

This uses a conditional Rational Quadratic Spline flow where the spline parameters are output by a neural network taking the parents as input. This can model complex, multi-modal, and skewed conditional distributions.

### Mechanism Properties

| Mechanism | Form | Gaussian $p(x\|\text{pa})$? | Linear Mean? | Additive Noise? | Symmetric? |
| :--- | :--- | :---: | :---: | :---: | :---: |
| **Linear** | $x = A \cdot pa + B \cdot \epsilon + b$ | ✅ | ✅ | ✅ | ✅ |
| **Nonlinear Noise** | $x = A \cdot pa + f(\epsilon) + b$ | ❌ | ✅ | ✅ (transformed) | ✅ |
| **Nonlinear Parents** | $x = \mu(pa) + \sigma(pa) \cdot \epsilon$ | ✅ | ❌ | ❌ (heteroscedastic) | ✅ |
| **Universal** | $x = f(pa, \epsilon)$ | ❌ | ❌ | ❌ | ❌ |

## Supported Structures

These mechanisms can be combined with various graph structures:

- **Chain**: Sequential dependency ($x_0 \to x_1 \to \dots \to x_n$)
- **Fork**: Common cause ($z \to x_1, z \to x_2, \dots$)
- **Collider**: Common effect ($x_1 \to y \leftarrow x_2, \dots$)
- **Random DAG**: Randomly generated sparse lower-triangular DAGs.
- **Dense**: Fully connected DAG.

## Usage

Benchmarks can be created using the factory functions in `pgms.factories`.

```python
import jax
from structflow.pgms.factories import make_chain_pgm, make_random_pgm

key = jax.random.PRNGKey(0)

# 1. Create a Linear Chain PGM
# p(x0) -> p(x1|x0) -> p(x2|x1) ...
linear_chain = make_chain_pgm(
    n_nodes=5, 
    mechanism_type="linear", 
    key=key
)

# 2. Create a Universal Random PGM
# Random DAG structure with fully nonlinear mechanisms
universal_dag = make_random_pgm(
    n_nodes=10,
    mechanism_type="universal",
    sparsity=0.3,
    key=key,
    hidden_width=64,  # NN width for parameter network
    num_bins=8        # Number of spline bins
)

# 3. Sampling
sample = universal_dag.sample(key)
# Returns: {'x0': array(...), 'x1': array(...), ...}

# 4. Evaluation
# `log_prob` is exact only for *tractable* (ancestral) queries: a node given
# its parents, or any ancestrally-closed set of variables (see Theorem 3.2,
# "Asymmetry of Marginalization", in the paper). Non-ancestral queries — e.g.
# inference of an ancestor given a descendant, or a query that requires
# marginalising out hidden variables — raise NotImplementedError.

# The full joint is always tractable:
log_prob_joint = universal_dag.log_prob(universal_dag.sample(key))

# In the linear chain x0 -> x1 -> ... a child given its parent is tractable:
chain_sample = linear_chain.sample(key)
log_prob_cond = linear_chain.log_prob(
    chain_sample,
    targets={'x1'},
    conditions={'x0'},   # x0 is the (only) parent of x1
)
```
